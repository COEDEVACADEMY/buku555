# Project Blueprint: Personal Debt Management Application "Buku 555"

## 1. Executive Summary

This document outlines the development plan for a personal debt management application named "Buku 555". The application will serve as a digital ledger for tracking personal debts, allowing users to record, manage, and settle debts owed to them. The primary currency for all transactions will be Malaysian Ringgit (RM) and the language of the application will be Bahasa Malaysia.

## 2. Branding and Design

*   **Application Name:** Buku 555
*   **Language:** Bahasa Malaysia
*   **Theme:** The application will have a nostalgic theme reminiscent of a classic "Buku 555" notebook, with a yellow background and black text.

## 3. Core Features

### 3.1. Debt Record Management

*   **Add New Debt:** Users can create new debt records, including the debtor's name and the principal amount. The application will automatically timestamp the entry with the current date and time.
*   **Debt Payment:** Users can record full or partial payments made by a debtor.
*   **Payment History:** A detailed history of all payments made towards a debt will be maintained and easily accessible.

### 3.2. User Interface

*   **Tabbed Navigation:** The application will feature a simple and intuitive three-tab navigation system:
    *   **Home:** A dashboard providing a summary of outstanding debts.
    *   **Not Paid:** A list of all outstanding debts.
    *   **Paid:** A list of all fully settled debts.
*   **Search Functionality:** A prominent search bar at the top of the application will allow for quick and easy searching of debt records.

## 4. Technical Specifications

*   **Data Persistence:** All application data will be stored locally on the user's device using local storage. This ensures data privacy and offline accessibility.
*   **Currency:** The application will be hardcoded to use Malaysian Ringgit (RM) for all monetary values.
